# 第 5 步：匹配（为什么是这个甲方 / 这个团队 / 这个范围）

**只在题目要求选范围、或给定了甲方时做。**没有甲方的创业赛，这一步换成「为什么是我们」。

## 一、换甲方测试

方案写完后，把甲方（或品牌、业务线）换成它最像的一个竞争对手，再换成一个最不像的，看方案要改几处。改动少于三处，说明你做的是一个可以贴任何标签的通用方案，评委一眼能看出来。

**真正的匹配：方案换一个甲方就不成立。**

## 二、三步法

### 1. 找甲方的「唯一性资产」

每个甲方都有很多属性，要找的是「换一家就没有了」的那个：一段只有它有的历史、一项独家技术、一个它一贯被公认的优势、一个它正在公开押注的方向。

去哪找：官网和口号、最近几个月的官方发布、主推产品、年报里真金白银在投的方向。

差异化要落在这里，不能是行业里谁都能用的通用热门技术。给子品牌做新品，挂靠它现有的产品线、命名和 IP 体系，写成自然延伸。

### 2. 把创意翻译成甲方的语言

同一个创意，面向不同甲方，表述完全不同：面向一个靠社交身份感立足的品牌，讲身份宣言和用户传播；面向一个服务高净值客群的品牌，讲专属服务和会员终身价值；面向一个靠场景叙事立足的品牌，讲记忆和档案。创意是同一个，评委看到的是你对这个甲方理解得多深。

### 3. 嵌入甲方已经在做的事

不写「我们提议你们做 X」，写「在你们已经推进 X 的基础上，我们是下一步」。每个技术或业务模块都写成在甲方已有的能力、平台、渠道上延展；落地保障写清借用了甲方哪项流量、数据或场景。

这一步真正影响的是可行和可扩展：越能证明在甲方现有基础设施上能执行，评委越相信做得出来、推得开。

## 三、加分写法

- 主动引用甲方已有的技术和项目，说明方案可以快速落地。
- 和甲方公开的可持续或战略目标绑定。
- 给可量化的收益预期，每个数字都能说出参考了哪个同类案例。

## 四、跨界做新东西时

「甲方跨界做一个新产品 / 技术」这类方案，提前回答：为什么甲方要做这件事、为什么是这个甲方、甲方得到什么、用户为什么要用。答案落到甲方现有的短板上。

## 五、批评甲方时

- 用它自己公开宣称的目标做标尺，不拿另一类公司当标准。
- 措辞审慎，说明结论是基于哪些公开事实的推断。
- 分清「战略方向没错，是执行系统出了错」，保留方向、修系统。不贬低案主公司。
- 提改进方案前，先查它已经有哪些机制，不提议已经存在的东西；要说清已有机制为什么没起作用。

## 六、按题型换成别的匹配

| 题型 | 这一步做什么 |
|---|---|
| 营销命题，要求选范围 | 一句话讲清为什么是这个品牌 / 业务线；多品牌集团时，把候选放进横向对比表，用数据评估适配度，选资产符合品类约束、又能和先行者错开的那个。这份论证可以直接变成竞争格局 |
| 广告命题，品牌已给定 | 对齐命题策略单和产品调性 |
| 战略咨询 / 限时案例 | 能力杠杆与价值观一致：为什么这家公司能赢；守住题目给的价值观和禁区；方案与公司资源、文化、财务承受力是否匹配 |
| 创业 / 商业计划（没有甲方） | 为什么是我们：团队与项目的契合、已有的资源和实证；赛道和组别选择 |
| 投资 | 基本跳过，标的已指定；赞助方不等于案例主角，不要硬套赞助方的业务 |
| ESG / 公益 | 开放题换成 SDG 对齐和影响 KPI 设计；企业题做方案与企业战略和能力的匹配；政府题做与赛点资源禀赋的匹配 |
| 政策 / 经济 | 角色立场：站在题目给你的机构职责和目标上说话 |
| 甲方是政府、NGO、非上市公司，没有年报 | 借力点去政策文件、官方发布、公开报道、实地调研里找 |

## 七、AI 带这一步的动作

1. 先问：题目要你选范围吗？有没有甲方？
2. 有甲方：带学生做换甲方测试，再走三步法。
3. 没有甲方：让学生写「为什么是我们」三句。
4. 让学生说出一句：「这个方案只有 ___ 能做，因为 ___」。
