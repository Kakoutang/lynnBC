# 第 9 步：路演、视频、答辩

**只在题目要求时做视频；内容按当届规则定（讲团队还是讲方案）。**年度赛事的视频要求经常变，一律以当届官方文件为准。

## 一、团队素质视频（题目要求讲团队时）

- 按官方列出的能力维度逐项回答，每题一个**真实事件** + 具体做法。只讲团队，不讲方案。每位成员都要出镜。
- 评分档位往往很陡：泛泛表态（「我们很有韧性」）大概率只拿中档或零分；讲具体事件（「第二周我们推翻了原方案，因为……」）才有高分。
- 每个回答检查有没有具体名词（日期、数据、人、工具），没有就打回。
- 先让学生回忆赛程里真实发生的三到五件事，再往问题上对。不要反过来编故事。这也是为什么第 0 步要从第一天起记录团队过程。

## 二、方案视频 / 路演

- 按「场景痛点 → 方案能做什么 → 一个具体例子」走。
- 钩子开场，报方案名和一句话概念；结尾重复一次，回扣题目或甲方的战略。
- 按规定时长倒排：封面压到最短，核心板块各一两页，结论一页一两句话。超时的内容不计分。
- 录制时背景干净、着装正式、加字幕；不许剪辑的赛要一镜到底。

## 三、讲稿

- 讲稿逐页对应 PPT：每段以页名开头，标「翻页」，用设问句过渡。标出哪里要指图。
- 演示型 PPT 每页一个钩子，文字说明交给讲稿。
- 每位讲者开口先回顾前面队友的结论，结尾交棒。
- 平实口语，以学生能自然说出口为准，不追求华丽辞藻。每个数字和页面一致。
- 同一套分析按载体换写法：PPT 写结论句，口播写有画面感的场景。
- 先用中文把逻辑写透，再翻成外语口播稿。转写时删掉论证不稳的部分。

## 四、问答与答辩（通常单独计分）

- 预设评委最可能问的问题：为什么是你们、为什么做这个、数据从哪来、最大的假设成立吗、成本和周期、可行性和规模化。提前写好答案。
- 每个数字都能讲出来源、公式和代入过程。最大的假设会被直接拿来测。
- 每人至少负责一个板块，能接得住题。安排一次「红队」预演。
- backup 备好数据页。页数少不等于准备少。
- 被问到不熟悉的领域：不直接说「不了解」，也不硬编。先讲自己知道的事件、数据或政策，再承认经验不足，并说明会怎么补。
- 不用「以人为中心」「落地」这类看似什么都能解释的大词，用具体事实代替，否则会给评委留下追问的口子。
- 按轮次调整：前几轮评委抠细节和准确性，决赛评委更看投入、可行性和创新。

## 五、按题型

| 题型 | 第 9 步 |
|---|---|
| 营销命题 | 按当届规则（可能只讲团队，也可能讲方案）；决赛准备可行性和规模化追问 |
| 战略咨询 / 限时 | 去掉视频，换成现场汇报 + 问答；准备 twist 问题和评委插问；每个人都要发言 |
| 商业计划 | 做重，按规定时长（陈述 + 问答）准备；问辩考真实性 |
| 投资 | 路演和问答必做且单独计分，准备数据型 backup |
| 市调 / 实战 | 按规定的展示 + 答辩时长；可以放真实运营片段 |
| 研究型 / essay | 通常没有视频；有现场陈述时，准备追问、假设情境题和理论题 |

## 六、AI 带这一步的动作

1. 看赛题卡：要不要视频？讲什么？时长多少？问答多久？
2. 团队视频：让学生先列真实事件，再分配问题，每题压到规定时长能说完。
3. 路演：按时长倒排页数，检查讲稿和页面数字一致。
4. 问答：生成评委最可能问的十个问题，让学生逐个口头回答，再挑最弱的两个重练。
