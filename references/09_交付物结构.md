# 第 8 步：交付物结构

## 一、总原则

1. **结构完全照题面和规则来**：页数和字数上限（含不含封面、目录、附录）、官方模板、规定章节及顺序。题面给了结构就照搬。
2. **题面没给结构**：结论先行，按子问题的顺序一问一节，每节标题写这一问的答案。
3. **每一页标它回答的是必答清单第几条。**对应不上的删。
4. 不加题目没要的封面、欢迎页、致谢页和背景铺垫。
5. 评分维度嵌进对应模块里补强（画像旁边加包容考虑、价格加入门档、时间线加复用路径），**不要一页对一个维度机械切分，不要照抄评分表做目录。**
6. 做页面前先写提纲：每一部分放什么图、要证明什么结论、去哪里找资料。先写文案，再做设计。

## 二、开场

按题目来：
- 题目要求执行摘要、书面报告、战略咨询、投资、政策题：**结论先行**。第一页回答核心问题，或复述题目目标 + 一句话答案 + 三个支撑点。
- 路演、营销短版、商业计划路演：用钩子开场。一个具体的用户场景或原话、一个故事、一个设问，或几个对比鲜明的数字（并点破「这个对比就是整个故事」）。不用一两分钟铺背景。
- 题目带硬约束（价值观、营收目标、年限）：开场的推荐页就说明约束怎么被满足。

## 三、每一页

- **标题写成结论句**（或「主题：结论」），只读标题就能串起整套逻辑。
- 每张图配一句 takeaway，把数据和结论连起来。连不上的图删掉，不放凑版面的图。
- 每张图表当页标出处：自有调研写团队调研 + 样本量，二手数据写机构和报告名。完整参考放文末。
- 信息密的页拆成带编号的小模块或四宫格，每格一张图加一两句结论，不整页堆字。
- 数字做成大字加小标签；图表嵌在相关文字旁，直接标数值，不用浮动图例；能用图就不用表，能用表就不用字。
- 长段步骤文字压成编号流程图，每步几个词。
- 面向非专业评委：缩写第一次出现时展开，用评委熟悉的案例做类比。
- 分类不重不漏；清单标题说几条，内容就写几条。
- 正文只放结论和图表；原始数据、推算过程、详细清单、参考文献放 backup，留着回答追问。没想清楚的空壳页宁可删掉。

## 四、主线

- 各板块守住同一条故事线。讲问题时不能和前面夸过的优势打架，需要时限定范围。
- 市场分析和方案之间放一句承上启下的过渡，把「机会」和「我们的优势」接起来。
- 结尾收得回来：总结页用「问题 / 方案 / 建议」一一对应；回到题目原问句或核心结论；结论里不引入新论点。

## 五、按交付物形式的常见结构

以下是**题目没给结构时**的默认切法。题目给了就照题目。

**限页短版（3–5 页，常配视频）**
- 每页一个核心目的。营销类常见：市场洞察（需求真实存在、市场大、没被满足）→ 方案（技术支撑 + 体验）→ 商业化（能推广、能赚钱、可落地）。
- 题目给了 frame 表（逐行要回答的问题）时，按 frame 表顺序。
- 信息密度高，各页共用一套从方案概念推出来的视觉语言。

**10–20 页 deck（案例赛、课程汇报）**
- 执行摘要（问题、唯一建议、三点理由）→ 现状与关键洞察 → 按子问题各开一章（在哪里竞争 / 怎么赢 / 路线图 / 财务）→ 风险与对策 → 回到量化目标收尾 → 附录（假设、计算、来源）。
- 题目把问题分两层，章节就分两层；给了 criteria 清单，就按清单一节一节对应。

**限时案例（5–8 页）**
- 1 页问题 + 结论 → 1–2 页关键分析 → 1 页方案对比 → 1–2 页实施与财务 → 1 页风险与下一步。其余放附录。

**商业计划书**
- 中文赛常用标准目录：执行摘要（放最前、最后写）→ 产品与服务 → 市场分析 → 营销策略 → 运营 → 团队 → 财务 → 融资 → 风险。章节顺序和篇幅按评分权重排：社会价值、实践过程权重高的赛就放前面、写厚。
- 开头先让评委看到具体的产品，再进入市场分析。
- 收入模式和定价放进财务，不放在营销里。

**路演版**
- 一页一个大数字或一句话，完整论述写在讲稿里。去掉目录页、章节过渡页、致谢页。

**书面长报告 / 咨询报告**
- 执行摘要 → 引言（张力和外部威胁）→ 现状（只描述）→ 分析框架 → 根因 → 分阶段方案 → 影响、资源与风险 → 结论。篇幅向诊断和方案倾斜，不均匀拉长。
- 现状只客观描述，结尾一句过渡引出为什么要变；每个框架章节三步：一两句解释 → 套到对象上 → 一个中间结论。

**案例分析 essay（课程类）**
- 一句话重新定义问题 → 事实概述 → 用课程框架逐题分析 → 根因 → 备选方案（两个极端加组合）→ 推荐与实施 → 可迁移的经验 → 结论 → 参考文献。课程作业每章至少挂一个课上的框架。

**投资研究报告**
- 封面写结论（评级、现价、目标价）→ 投资摘要 → 业务 → 行业与竞争 → 财务分析 → 估值 → 风险 → ESG（以题目规定的标题为准）。每节标数据来源和截止时间。

**调查报告**
- 摘要（写清亮点和位置）→ 选题背景与研究问题 → 文献 → 调查方案设计 → 实施与质量控制 → 数据分析 → 结论与建议 → 附录。按打分项顺序排，正文附录分开。

**研究型 essay / 政策建议**
- 题目规定结构就照搬（例如现状、预测、风险、建议）。没规定：第一句直接给立场 → 证据 → 机制分析 → 风险或反方 → 建议。结论强度和证据匹配。

**财务模型（单独提交）**
- 假设表 → 计算表 → 结果表；假设都标来源；有敏感性分析。

## 六、视觉

评分把视觉和故事线并列时，排版要和分析一样打磨。配色和字体从方案概念推出来，不套通用模板。产品类方案要让评委「看见」产品（原型、建模图、界面配用户旅程）。咨询和金融类用克制统一的商务版式。

## 七、AI 带这一步的动作

1. 先看题面有没有规定结构。有就照搬，列出每一节对应必答清单第几条。
2. 没有就按上面的默认切法给一版目录，每页写一句结论标题。
3. 让学生用三到五句话讲完整套（每句是一页或一节的结论）。讲不完整，说明主线还没通。
4. 提醒：哪几条必答项还没有页面承接。
5. 急稿：只要每页的结论标题 + 必补项（定价依据、KPI、财务影响，按题目要求）。
