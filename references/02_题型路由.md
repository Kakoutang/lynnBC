# 题型路由：这道题属于哪类，十步怎么裁剪

先判**内容题型**，再叠加**赛制属性**（限时 / 封闭 / 实战 / 书面）。

**多类信号同时出现时：**
1. 以评分表里权重最大的维度定主类；权重相近时，以题面点名的交付物和术语定（例如出现 SDG、社会企业，E 为主）。
2. 叠加题型时，每一步取**评分表或题面点名的那一类**的做法；两类做法冲突，以题面为准。下表的「按题型」只是默认，题面和评分表永远优先。

## 一、判断信号

| 内容题型 | 题面里的信号 |
|---|---|
| **A. 企业命题：营销 / 产品创新**（含广告命题策划） | 具体品牌或事业部 + mission / brief / 命题策略单；可选赛道；出现「创新、重塑、新产品、新体验、未满足需求、上市策略」；广告类会给主题、品牌痛点、人群、口号、预算上限；评分是创新、可持续、包容、可行、可规模化，或洞察、策略、创意、落地 |
| **B. 战略咨询案例** | 一句话问题「公司怎样利用 ___ 实现 ___（带数字和年份）」；给大量案例材料和附录数据；2–4 个子问题；要求选择或排优先级、路线图、财务预测或投资分配；有禁区；评分是分析、方案、创意、可行、视觉 |
| **C. 商业计划 / 创新创业** | 不给具体题面或只给大框，项目自选；出现商业计划书、执行摘要、路演、组别、注册与股权、融资与退出、原型与专利；题目要求实际写在评分表里 |
| **D. 投资与金融** | 评级和目标价、多空和期限、限定股票池、估值模型、LBO、Go/No-Go、投委会、客户投资目标；规则写明不按收益评分、只用公开信息 |
| **E. ESG / 公益 / 社会创新** | SDG、社会企业、影响 KPI、受益人数、被定义好的硬目标；或企业 ESG 风险与机会；或乡村振兴、帮扶对象、政府赛点；或影响力投资 |
| **F. 市场调查与运营实操** | 调研型：调查报告、选题、文献、抽样与样本量、问卷或访谈、质量控制、查重；实战型：指定平台、直播短视频、真实订单或投放预算、严禁刷单；评分里真实业绩或调查工作量占大头 |
| **G. 经济学 / 研究型** | 要一个经济判断或政策决定、一个 essay 立场、一份研究论文；规定结构（现状、预测、风险、建议）；按字数计；开放数据集；评分看分析、数据来源、术语和答辩 |

| 赛制属性 | 信号 | 影响 |
|---|---|---|
| **限时** | 3 / 5 / 12 / 24 / 48 小时，现场拿题 | 砍掉一切不直接回答题面的步骤 |
| **封闭** | 不许上网、只给案例包、只能用案例事实 | 第 2 步改成挖透案例材料，不做外部研究、不做访谈。**开赛后本教练也属于外部帮助，不在赛中使用** |
| **实战** | 要真实运营、投放、试点数据 | 加一步「实地执行」，它是拿分主体 |
| **书面** | 报告 / essay / 计划书 | 第 9 步看分值：展示、视频、答辩单独占较大比例时（例如报告分和展示分分开算），第 9 步照样做重；没有展示环节才压缩 |

## 二、各类评委奖励什么

这张表是 Lynn 和公开资料归纳的经验。对学生引用时写成「推断：___」，不说成本题评委的偏好；本题以评分表原文为准。

| 题型 | 评委奖励 | 不奖励 |
|---|---|---|
| A 营销命题 | 创新从真实需求长出来；可落地；与出题方业务和市场需求相关；评分表有可持续、包容时，它们长在方案里；演示观感 | 行业研究做得多；技术堆砌；完整商业计划（题目明说不要时） |
| B 战略咨询 | 回答了题目（常单独计分）；有明确取舍和优先级；举措回扣量化目标；财务扎实；先界定问题、先讲答案 | 罗列选项不选；只做一个新产品创意；铺背景 |
| C 商业计划 | 痛点真实且有规模；有实证（原型、用户、试点、专利）；单位经济和盈利路径；团队与项目匹配；按评分表侧重（有的赛社会价值、实践过程权重高于商业） | 纯概念；讲技术不讲用户 |
| D 投资金融 | 估值方法得当、假设讲得通、模型和逻辑一致；数据来源合规；问答能用数据守住立场 | 大胆的个股判断；收益预测对错 |
| E ESG 公益 | 影响可量化并随营收增长；商业上站得住；真实验证；对题目指定的人和地方有用；企业事实准确 | 公关稿式的正面描述；照搬企业 CSR 原文 |
| F 市调实操 | 结论与数据的关联、方法适合、调查工作量；真实业绩；严格按策略单作答 | 创新（权重很低）；刷单造假 |
| G 经济研究 | 术语准确；推理链和结论相符；直接回答题目并反驳最强的反方；完整覆盖点名的每一块；答辩 | 产品、品牌、营收 |

## 三、十步按题型裁剪

默认原则：**题目点名的就做重，没点名的就压缩或删掉。**

| 步 | 默认 | 按题型 |
|---|---|---|
| 0 组队 | 做轻：核对人数和资格，按交付物和评分结构分工 | **最优先：评分表或陈述评分里只要出现团队、每人参与类维度（不论分值大小），一律写「加重」**，这条压过下面各类的默认；C：团队常单独计分，专业结构要和项目匹配并写进计划书；B / 限时：赛前定好角色，按讲稿段落分工，每人都要发言；F 实战：提前分好执行角色；G 团队赛：按陈述和答辩分工（团队不计分时做轻）；F 调研型：按问卷设计、实地执行、数据分析、报告分工，提前排好执行；G essay：个人赛跳过 |
| 1 读题 | 做得最重 | 所有类都一样重。C：改成读评分表和参赛规则；E：把题目定义的硬指标抄成验收清单；D：确认要给的动作、角色、规定章节、数据边界 |
| 2 研究 | 压缩：只查能直接支撑答案的数据 | A：官方材料给的背景基本够用，只补支撑痛点的 1–2 个数据；B：以吃透案例材料为主；封闭赛：只用案例包；C：按评分要求写行业部分，常要一手实证；D：做重但收窄到财务、行业、可比公司；F 调研型：变成文献研究，只留实际用到的；G 闭卷：赛前背框架；G 开卷且评分点名研究或深入分析：加重，来源多样、能互相印证 |
| 3 问题 / 痛点 | 用题面给定的问题；题目要科技时，科技从痛点推出 | A：做重但只占一两行；B / 限时：改成根因与障碍诊断，题目问才单列；C：做重，是整份方案的起点；D：换成投资逻辑和关键驱动；E：痛点必须落在题目指定的人、地方或企业上；F 调研型：换成研究问题；G：换成问题界定 |
| 4 对象 | 只在题目点名人群时做 | A：题面没点名人群调研时，压成一句目标人群并用来回答包容；题面点名人群调研时做重；B：题目点名人群才做，否则换成市场 / 国家 / 业务段的筛选矩阵；C：做客户画像加用户测试；D：基本删掉，财富管理题换成客户画像；E：换成受益人或利益相关方；F 调研型：换成调查对象与抽样，做最重；G：换成受影响人群 |
| 5 匹配 | 只在题目要求选范围或给定了甲方时做 | A：一句话讲清为什么是这个品牌 / 范围；B：变成能力杠杆与价值观一致；限时：变成方案与公司资源、文化、财务承受力的匹配；C：没有甲方，换成「为什么是我们」+ 赛道匹配；D：基本删掉，标的已指定；E：开放题换成 SDG 对齐与影响 KPI 设计，政府题换成与赛点资源的匹配；G：换成角色立场 |
| 6 方案 | 做重，形式由题目要的结论决定。F 调研型的「调查实施」（问卷发放、访谈、质量控制）也在这一步，评分单列时做重 | A 产品创新：一句话概念 + 核心功能；题目点名科技时写技术怎样服务痛点，评分有可持续、包容时写具体机制；A 广告传播：洞察 → 策略 → 创意 → 内容、排期、渠道、预算；B：选择 + 2–4 个举措 + 分阶段路线图；限时：2–3 个备选 → 打分矩阵 → 1 个推荐；C：创新点归类 + 实证；D：建议与估值；E：形式按题目（社会企业、整改项目、金融工具）；F：调查方案 / 创意传播 / 真实执行；G：明确立场 + 反驳替代方案 |
| 7 财务 / 定价 / KPI | 题目点名才做，做到要求的深度为止 | A 产品创新：题目要售价和 KPI 时，价格区间 + KPI + 一句规模化路径（KPI 数量没规定时，「2–3 个」是默认假设，非原文）；A 广告传播：给了预算只做预算分配，点名效果衡量或投入产出比才加；B：几乎必做，财务预测与目标拆解；限时：只用案例数据做量级估算；C：盈利路径、单位经济；多年预测和融资只在评分表或材料清单点名时做，按评分权重控制篇幅；D：核心，权重最高；E：商业 KPI 和影响 KPI 两条并写联动；F 实战：KPI 就是平台真实业绩；G：只在点名时做 |
| 8 交付物结构 | 完全照题面和规则；没给结构就结论先行，一问一节 | 见 [09_交付物结构.md](09_交付物结构.md) |
| 9 路演 / 视频 | 只在题目要求时做视频；路演按规定时长倒排；问答单独准备 | 见 [10_路演视频与答辩.md](10_路演视频与答辩.md) |
| 10 自检 | 题目的评分表逐项打分 + 必答清单打勾 + 红线 | 限时：压成交稿前 20 分钟的核对；C：加资格和格式检查；D：加数字与模型一致、来源合规；F：加查重、去身份信息、数据真实 |

## 四、限时赛的压缩版

只剩几小时或一两天时：
1. 读题 → 必答清单 + 一句话结论（30 分钟内）。
2. 分工按必答清单切，每人一块，同时开工。
3. 只查能直接支撑答案的数字。
4. 先写每页的结论标题，再填内容。
5. 题面或评分点名财务影响、风险时，即使粗估也要有；没点名的放进问答备用，不占页面。
6. 交稿前 20 分钟：必答清单逐条打勾、页数、匿名、数字能否追溯、文件提前上传。

以上是**赛前模拟和赛前准备**用的。正式开赛后，本教练不参与（见 SKILL.md 停止条件）。

## 五、内部记录格式（不展示给学生）

判断完题型后，在内部这样记，用来决定带学生走哪几步。对学生只说下一步做什么，不说题型和裁剪：

```
内容题型：___（主类）＋ ___（如有叠加）
赛制属性：限时 是/否/待确认 · 封闭 是/否/待确认 · 实战 是/否/待确认 · 书面 是/否/待确认
十步裁剪：
0 组队：加重 / 默认 / 压缩 / 跳过 —— 一句理由
1 读题：……
…（0 到 10 每一步都写，一行一步）
```

每一步的判断都要能从赛题卡或评分表里找到依据。规则没确认时，先按现有信息选一个值，再加「（待确认：___，确认后可能改为 ___）」，不只写「待确认」。标签和理由要一致：理由说的是加重，就写加重。
