# 第 7 步：财务、定价、KPI

**题目点名才做，做到题目要求的深度为止。**

评分要求按轮次不同时，按当前轮次回答；轮次待确认时分两行写：「第一轮做到 ___；后面的轮次如果要求 ___ 再加」。「放 backup 应对问答」只适用于有问答环节的轮次。

| 题目说 | 做到哪 |
|---|---|
| 「给大致售价」「不需要商业计划」 | 一个价格（或区间）+ 依据 + 2–3 个 KPI + 一句规模化路径；评分有「可行」时，加一句资源边界（要什么、多久、靠谁）。不做损益表、ROI、多年预测 |
| 评分点名商业模式、财务可持续、单位经济，没点名预测 | 单位经济 + 分阶段走到收支平衡的路径 + 商业 KPI 与影响 KPI 的联动（社会企业）。多年损益不进主文件，最多放 backup 应对问答 |
| 给了预算上限 | 预算分配；点名投入产出比才测算 |
| 要商业计划 / 财务预测 | 完整：收入模式、定价、成本、多年损益、回本、融资需求 |
| 战略题给了量化目标 | 财务预测 + 目标拆解（证明怎么从现在走到目标）或投资分配 |
| 限时案例 | 用案例数据做量级估算，财务影响一定要有 |
| 投资题 | 核心：历史分析、预测、估值、回报、敏感性 |
| 社会企业 | 商业 KPI 和影响 KPI 两条，并写两者怎么联动 |
| 实战赛 | KPI 就是平台真实业绩，不做预测 |
| 题目没提 | 不做 |

## 一、可行性

可行性常常是生死线。写清资源边界：要多少钱、多长时间、需要什么合作方和条件；实施成本估算；潜在用户规模。确保在甲方现有人手、预算和时间内做得到。只谈概念不谈资源边界，会在可行性上直接丢分。

第 6 步列出的每个功能、技术模块、线下体验，都要能估一个成本，进入这里的成本表。

## 二、定价（题目涉及产品或服务时）

**三个核心因素：成本是地板，顾客价值是天花板，竞争是参考系。**

- **成本**：不只算原料或生产，完整成本包括显性（原料、包装、生产、物流）、隐性（品牌、研发分摊、渠道、营销、门店）和机会成本（定位带来的价格区间限制）。新技术要算开发维护，新渠道要算运营。
- **顾客价值**：没有竞争时，顾客感受到的价值就是上限，和成本关系不大。用户买的不只是功能，还有情感、社交、体验价值。说清楚目标用户愿意为什么付费。
- **竞争**：竞品价格是重要参照，但不是唯一依据。说清你在竞争格局里的位置。

几个常用的定价逻辑：
- **心理账户**：同一产品，自用、犒赏自己、送礼、收藏，价格预期完全不同。定位决定它进哪个账户。
- **锚定**：放一款高价旗舰或限量款，不为卖量，为主力款创造参照；大规格的高价让小规格显得划算。
- **规格梯度**：小规格降低尝试门槛，大规格或订阅服务忠诚用户。
- **奢侈品不用快消思维压价**：服务高端人群时，太便宜反而让人怀疑价值。

定价要回答五个问题：
1. 定价多少？给具体数字。
2. 依据是什么？成本、价值、竞争各一句。
3. 在竞争格局里什么位置？对标谁，高还是低，为什么？
4. 毛利够不够撑渠道、营销、运营？
5. 有没有梯度？

**常见错误**：只给数字不解释；定价和目标人群脱节；忘了渠道分成；只有一个 SKU 没有梯度；价格和品牌定位矛盾（定位决定定价的大部分）。

## 三、收入预测与财务

- **自下而上拆**：用户规模 =「甲方公开的客户基数 × 渗透率」或「数量 × 单体效率」。参数从第 2 步的底表取。
- **假设显式列出**：用户增速、付费转化、复购、合作收入，每个从历史均值出发，再说明为什么上调或下调。
- **从最小单位算起**：单项成本和售价 → 单笔利润 → 乘以写明的规模假设 → 多年收入。每个成本项写明金额怎么来的。
- **顺序**：初期投资 → 收入 → 成本 → 利润 → 回本周期。先列假设（税率、固定成本、可变成本占比、一次性投入），再给逐年损益；页上用图表呈现，每年配一句阶段特征；推算过程和盈亏平衡放 backup。
- **页上的文字结论必须和表里的数字一致。**
- 订阅、会员、平台类：算单位经济。教练引用下面的骨架，不现场编公式：
  - 单客年收入 = 单价 × 年购买次数 × 留存率
  - 单客月毛利 = 单客月收入 × 毛利率
  - 回本月数 = 获客成本 ÷ 单客月毛利
  - 用户终身价值 = 单客月毛利 × 平均留存月数
  - 总收入 = 客户数 × 单客年收入
  - **单客指标和总量指标不能写在同一个式子里。**
- 关键假设做高、中、低三种情景。
- 创业类：融资需求、资金用途、出让股权、估值依据、里程碑（题目要求时）。
- 投资类：指标真正算出来（NPV、IRR、回收期、目标价），展示参数表和计算过程。只列公式等于没答。

## 四、KPI

- 写出计算公式：用户数 × 客单价 × 复购率 = 营收。每个指标有事先的预期和时间节点。
- 分两组：交付或体验类、商业结果类。用甲方现有数据做基线。
- 题目给了量化目标，就用它当北极星指标，往下拆先行指标。
- KPI 从第 3 步的验证假设延伸出来，和痛点对得上。
- 社会企业加影响 KPI（受益人数、口径写清）。

## 五、落地计划

- 分阶段：试点 → 复制 → 规模化。每阶段两三个具体动作和可检验的目标。
- 分档落地：核心场景做完整版，普通渠道用简化版，线上用工具承接。
- 首批试点用条件清单筛出来。
- 多年计划每年一个主题，用甘特图；细节放 backup。

## 六、所有数字都要有依据

- 粗估可以，但要写明假设。
- 增长和回报不能写成没有推导的跃升；说增长要讲清和什么基线比。
- 找不到来源的精确数字、自编的百分比、靠公式算出来的天文数字、「已达成合作意向」这类不存在的事实，一律删掉。

## 七、AI 带这一步的动作

1. 先看赛题卡：题目要求财务做到多深？按上表定深度，不多做。
2. 定价：先问定位进哪个心理账户 → 三个对标的价格 → 成本结构（估算标「估」）→ 2–3 档梯度 → 用常见错误反查。
3. 财务：先列假设表，再算。检查参数是否来自底表。
4. KPI：让学生写出公式和基线。
