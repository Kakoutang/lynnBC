# 第 1 步：读题与赛题卡

> 读题做得最重，但在你内部做。花在拆题上的 1 小时，能省后面 3 小时返工。没搞懂得分逻辑之前，不想 idea，也不让 AI 出创意。

## 一、赛题卡：从题目原文抽出这些

学生贴进题目和规则后，逐项抽取。

**硬规则：**
- **每一格只能来自学生贴的原文。**原文没有的一律写「待确认：去 ___ 找」，不用自己知道的赛事背景补全，哪怕比赛名字暗示了某些信息（主办方、届次、评委、赛区、是否邀请赛）。
- 「待确认」后面只写去哪找，不附「通常」「一般」「大概率」之类的推测。
- 原文只出现在某个赛区或某份通知里的要求，标明来源（「据 ___ 赛区通知」），提醒核对本赛区。
- **17 行全部核对，顺序不变。**有内容或待确认的行逐行列出；结论是「不需要 / 按默认处理」、又没有待确认要追的行，一律合并成最后一行「不适用：___、___（原因）」。第一回合的赛题卡尽量控制在 12 行以内。
- **「抽不到时」分两类**：事实类（评委、匿名、页数、AI 政策、届次）只写「待确认：去 ___ 找」，不给默认值；做法类（角色、数据边界）可以给备用做法，但必须标「默认假设，非原文」。默认角色按题型给：案例 / 战略题是外部顾问向管理层汇报；营销 / 广告命题是向出题品牌提案的外部团队；调研题是研究者；政策题是题目给的机构；自选创业题是创始团队。
- 不写原文没出现的文件名或术语。「去 ___ 找」只能填原文出现过的文件名，或者用泛称「去规则原文 / 主办方发的文件找」，不自造「本届参赛通知」「赛区通知」「官方指引」之类的名字。只有原文明确出自某份通知时才标「据 ___」。
- 原文没写年份时，第 1 行写「届次：待确认（原文没有年份，可能是往届题）」。
- 原文年份早于当前年份时，写明「这是往届题：按模拟练习处理，还是另有本届题面，待确认」。原文混了多个届次的题时，只把学生要参加的那一届列进必答清单，其他列为「往届题（可作模拟）」。别的届次或媒体报道里的赛制信息不进 A 段，确实要用就写进赛题卡对应行，标「据 ___ 报道，本届待确认」。规则段每一条也标届次，分不出的标「届次待确认」。问更新版本时用「你手上有没有比这份更新的本届题面和规则？」，不给下一届起年份名字。
- 一场比赛有多个案例或多轮时，时长、交付物是按每个案例 / 每轮算还是合计算，原文没写就标待确认，不写成「每个案例各一份」。
- 原句里的限定词（人群、年龄、地域）作用范围有歧义时，照抄整句，标「限定范围待确认」，把两种读法都列出来，不自己拆。
- 原文能抄就抄，不改写。从原文推出来的（例如「基于目标群体调研」推出要一手调研）标「推断」。

| 项 | 怎么抽 | 抽不到时 |
|---|---|---|
| 赛事、届次、当前轮次 | 赛事名、年份、初赛 / 半决赛 / 决赛。每一轮交付可能不同，年度赛事每届规则都会变 | 问学生是哪一轮、拿到的是哪一年的规则。不套往年格式 |
| 主办方、案例公司、角色、评委 | 主办方是谁、案例公司是谁（两者常常不是同一家，赛事名里的「×」联名不算出处）；题目让你扮演谁（外部顾问、管理层、分析师、投委会、政策制定者）；向谁汇报；评委是谁（企业高管、HR、咨询合伙人、教授、投资人） | 角色没写时默认：外部顾问向案例公司管理层汇报，并在方案里写明这是假设。**评委身份、问答形式没写就标待确认，不用默认值填** |
| 核心问题原句 | 逐字抄：题目的一句话问题 / mission / 主题 / 策略单的主题 / essay 题目 | 开放题（只问「下一步怎么做」、自选项目、没列问题）：让学生先写一句话问题陈述，你审过才往下 |
| 点名必答清单 | 子问题、「你的方案应包括」清单、frame 表的每一行、策略单点名的项、规定章节或段落，**逐条编号** | 用评分表维度当清单；创业类用材料清单 + 评分表 |
| 要求的结论形式 | 一个新产品 / 体验；一个选择（哪个市场、哪段价值链、哪个人群，要排优先级）；一个投资动作（评级、目标价、Go/No-Go）；一个政策决定；一个立场；一份调查结论；真实业绩 | 按开放建议题处理：必须给一个明确推荐，不能只罗列选项 |
| 量化目标与年限 | 所有数字和年限（收入增长多少、到哪一年、覆盖多少人） | 不自己发明大目标，只用 KPI 说明怎么衡量成功 |
| 范围或赛道选择 | 是否要自己选：赛道、业务范围（集团 / 事业部 / 品牌）、组别、方向 | 按不需要选处理，跳过选范围的论证 |
| 硬约束与禁区 | 预算上限、指定口号、指定人群、指定资源；不准提的东西；题目点名的「已经试过的」「行不通的」方案 | 只守通用合规 |
| **题目明说不用做的** | 只收原文明确写了「不需要 / 不要 / 不必」的内容。投稿类别限制（「本命题不收 X 类作品」）是规则，放进硬约束，不等于方案内容里不能出现 X。例如「不需要完整商业计划」「不要封面和致谢页」「视频不讲方案」「不必介绍机构」 | 以评分表为边界，评分表里没有的项压缩 |
| 交付物规格 | 页数（含不含封面、目录、附录）、字数、比例、文件大小和格式、视频时长和内容、陈述 + 问答时长、官方模板、执行摘要 / 一页纸、正文附录是否分开 | 待确认：让学生找规则原文。拿到之前，篇幅类和自己控制的时长（陈述、视频）按最紧的口径；问答时长有冲突时按较长的准备题库。原文没有任何页数口径时，写「页数待确认」，不说「按最紧口径」 |
| 评分表与权重 | 每个维度和分值；是否分开独立评（方案分和团队分各算）；有没有单列「回答题目的程度」；问答是否单独计分 | 有往届公开权重就用，并注明；都没有就按必答清单等权自检 |
| 资源与数据边界 | 能否上网、能否用电脑；能否用需要登录的数据库；AI 政策和披露要求；是否只能用案例材料；外援规则（能否联系出题方、导师时长、问答时能否互相商量）；是否必须标来源。原文的限制条款逐条抄全 | 待确认。备用做法（默认假设，非原文）：只用公开资料并标来源，AI 使用要能披露 |
| 时间形态 | 限时（几小时到 48 小时）/ 长周期（几周到一学期）/ 实战期（需要真实运营数周）；**具体截止日期**和起算日。只根据截止日、可用时长、「现场拿题」之类的原文判断；修改窗口、轮次间隔不能当依据 | 待确认：问截止日。学生只给了时长，写「长周期 X 周，截止日期待确认」 |
| 团队与资格 | 人数、年龄、同校 / 同国、学历、是否要注册公司、股权、营收上限、是否每人都要发言 | 提醒核对，资格不符可能直接被取消 |
| 匿名与身份 | 是否不得出现学校和姓名 | 待确认：去规则找。提醒学生查 |
| 实证要求 | 是否要一手调查、原型、用户测试、试点、真实平台数据、授权书 | 待确认。备用做法（默认假设，非原文）：按纸面方案处理 |
| 技术要求与题面定义的术语 | 题目是否点名技术；题目自己定义的关键词（例如它说的「有意义的工作」是什么口径） | 技术不单开章节，只在服务痛点时出现；没定义的术语由学生定口径并写明假设 |

## 二、必答清单就是目录

必答清单固定分三段，合起来编号：

- **A. 题目点名必答**：逐条编号，标〔题面〕。
- **B. 评分维度**：每个维度一行，写它要嵌进哪一节（不单开页），标〔评分表〕。
- **C. 规则硬性要求**：页数、时长、模板、匿名、格式，标〔规则〕。

skill 自己认为「最好有」的东西**不进清单**（例如题目没问的风险页、行业研究）。可以在清单下面单列「可选，不占页面，留作问答备用」。

交付物不止一件时（例如 PPT + 视频），每一行标它落在哪件交付物里，不要把视频要回答的内容塞进 PPT。

**怎么区分规定顺序和内容清单**：只有原文出现「按以下顺序 / 章节结构 / 模板 / outline / 第 1 段写 ___」之类的字眼，或给了官方模板文件，才算规定顺序，照搬不调整。「要求包含 / 应涵盖 / should include / must cover」只是内容清单，不规定顺序，按结论先行排并说明理由。分不清时写「顺序待确认：先查有没有官方模板」。

**合并重复**：约束只是要求每一问分几层回答（例如「两层都要答」）时，不新开 A 行，在相关 A 行后标「分两层答：___ / ___」。A、B、C 三段之间任意两段说的是同一件事（例如交付物本身和它的规格、官方封面的必填字段和「必须用官方封面」），合并成一行，标全部来源，不重复编号。C 段只放 A 段没覆盖的格式要求。

**B 段写法**：评分表未公开时，B 段只写一行「B：评分表未公开，按 A 段等权自检」；报道里评委称赞的点只放进赛题卡评分行，标「据 ___ 报道，不是评分表」，不编号。维度挂到哪一节、原文没给对应关系时，箭头后标「（推断）」。评分表有带权重的维度时，按维度逐行列（写权重），细项挂在维度下；原文没写细项归哪个维度，细项单列并标「归属待确认」。一个维度原文含多个对象（公司 / 市场 / 客户）时，按对象分别写嵌进哪一节。评分表点名的理解类维度（市场、公司、客户），对应内容不能标「题目没问」，写成「不单开，嵌进 A__ 作为证据」。B 段只写嵌进哪一节，不写怎么写。

**D 段（如有）**：后续轮次（复赛、决赛）另外要求的内容，逐条编号放 D 段，标「进入该轮后启用」，不合并成区间。

交付物里每一页或每一节都要对应清单上的一行；对应不上的，删掉。

这份清单贯穿全程：
- 第 8 步搭结构时，每一页标它回答的是清单第几条。
- 第 10 步自检时，逐条打勾。
- 压缩篇幅后，回头核对每一条是否仍有对应段落。删段落时最容易把必答题一起删掉。

题目给了问题清单时，导航和章节要让评委能对照题目逐项找到答案；收尾页的标题可以直接用题目原问句。

## 三、读出题方的意图

从「为什么办这个比赛」反推评委偏好：
- **企业办赛**（传播品牌、招人、收集创意）：方案必须能落地，要体现企业公开倡导的价值观，站在企业或具体部门的角度提案，像「递投名状」。命题文件里的例子、关键词、合作部门介绍，都是偏好信号。
- **咨询公司或商学院办赛**：案例公司是另一家，评委看的是分析是否严谨、是否回答了题目、建议是否可行，不是「替出题方说话」。
- **政府、公益、学校办赛**：看是否对题目指定的地方和人群有用、成本是否低、能否持续。
- **投资、金融赛**：不按收益对错评分，看研究质量、方法是否得当、推理是否站得住。

## 四、先定义真正的问题

不急着跳到方案：
1. 题目已经给了痛点、核心问题或关键词定义，**就用题目的原话**，不另起炉灶。
2. 题目开放时，从材料里找几组关键矛盾（通常是供给和需求的错配），每组一个破局点，后面的方案从破局点长出来。
3. 题目有多个赛道时，每个按「痛点 → 机会 → 破题点」拆一遍，再只选一个做深。
4. 自选题时选窄：要么选一个不为人知但做出了成绩的对象，要么给熟悉的对象找一个大家不知道的切口；对象最好正处在转型或扩张期，有一个真实的张力。

## 五、新手的起步顺序

1. 先弄清交付物每一页 / 每一节要放什么（第 8 步的结构）。
2. 再看往届获奖作品，各板块组合起来是什么样。**只看结构和论证方式，不抄概念。**
3. 最后带着清单去资料包找材料。有官方模板时，先确认是否使用，并逐页对照模板检查必答项。

## 六、AI 带这一步的动作

**这一整张赛题卡和必答清单都是你内部的工作底稿，不展示给学生。**

1. 在内部把赛题卡和必答清单做完、记住。
2. 对学生只说：这题要交什么、评委看什么、最容易丢分的一两个坑、第一步现在做什么（见 SKILL.md「第一条回复的样子」）。
3. 原文缺的信息，只有挡住当前这一步才问，一次问一个，说清楚为什么需要。年份届次、赛区、评委身份这类不影响当前动作的，不问。
4. 学生之后补充的信息，你在内部更新赛题卡，不用告诉他「已更新」。
