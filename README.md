# lynnBC · 商赛 AI 教练

**把任何一道商赛题目贴进去，它会帮你拆清楚题目要什么，然后一步一步带你把方案做出来。**

lynnBC 由 Lynn 基于多年大学生商赛辅导经验打造。它不针对某一场比赛，而是一套通用的方法：读懂题目、找准问题、搭好结构、按评分标准自检。

## 适用范围

| 比赛类型 | 例如 |
|---|---|
| 企业命题 / 营销创新 | 欧莱雅 Brandstorm、快消品牌命题赛 |
| 广告策划 | 大广赛策划案类 |
| 战略咨询案例 | 贝恩杯、各商学院案例赛、限时案例赛 |
| 商业计划 / 创新创业 | 互联网+、挑战杯、BPA |
| ESG / 社会创新 | ESG 案例赛、乡村振兴、社会企业类比赛 |
| 投资与金融 | 投资研究、估值、银行案例 |
| 市场调查 | 正大杯等调研类比赛 |
| 经济与政策研究 | 经济学挑战赛、政策建议类比赛 |

交付形式不限：3 页 PPT、20 页 deck、30 页策划案、商业计划书、路演、视频、调查报告、essay 都可以。

## 它怎么帮你

1. **读懂题目**：告诉你这道题到底要交什么、评委看什么、最容易丢分的地方在哪。
2. **给出第一步**：具体到做什么、怎么做、做到什么程度。
3. **审你的产出**：你做完发回来，它指出最关键的问题，再给下一步。
4. **带到交稿**：研究、问题定义、目标人群、方案、财务预算、结构搭建、路演准备，最后按评分标准自检。题目没要求的步骤会自动略过。

核心原则只有一条：**题目要什么就做什么，题目没问就不做。**

lynnBC 是陪练式的：它负责拆题、带路和审稿，方案由你主导完成。这样做出来的东西，评委追问时你答得上，比赛结束后能力也留在你身上。

## 安装

在 WorkBuddy、Claude Code 或 Codex 的对话框里发送：

```bash
git clone https://github.com/Kakoutang/lynnBC.git ~/.claude/skills/shangsai-coach
```

装好后**新开一个对话**，把题目、规则、评分表原文贴进去，说「我要参加这个比赛」即可。

其他工具的 skills 目录：Codex 为 `~/.codex/skills/`，WorkBuddy 为 `~/.workbuddy/skills/`。

## 使用提示

- 题目原文贴得越完整，判断越准。
- 也可以只问一个具体问题，例如「这页标题行不行」「要不要做五年预测」「按评分表帮我打个分」。
- 正式比赛进行中（限时、禁止外部帮助）请不要使用。拿往届题练习没问题。
